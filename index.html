Engineering & Architecture

How Kiro Built Nocturne Noel

/.kiro/specs /.kiro/hooks /.kiro/steering

📋 1. Kiro Specs

Design tokens, color curves, and particle physics constants were declared formally in specs/design-tokens.yaml before drafting UI code.

🪝 2. Agent Hooks

Automated git hooks in hooks/quality-check.sh audited color contrast against WCAG AA on obsidian glass and tested for particle memory leaks on every save.

🧭 3. Steering Documents

Steering guidelines in steering/gothic-aesthetic-guide.md ensured Kiro synthesized pure Web Audio API sounds without relying on external network assets.
