## 🌟 Overview

**Nocturne Noel** is an interactive dark-mode holiday web experience created for the **Kiroween 2026 Hackathon (Costume Contest Track)**. Inspired by Tim Burton's classic *The Nightmare Before Christmas*, the project reimagines holiday cheer through a sophisticated gothic-noir lens—subverting generic holiday templates with deep obsidian glassmorphism, procedural crystalline snowfall, rising hearth embers, and interactive mystical fortune generation.

---

## ✨ Key Features

- **🖤 Hauntingly Elegant UI/UX**: Deep obsidian tones layered with emerald velvet, blood crimson ribbons, and antique gold filigree, rendered with fluid glassmorphic cards and glowing borders.
- **🔮 Interactive Wishing Chamber**: Whisper your holiday wish into the enchanted crystal to receive bespoke gothic holiday blessings and collectible illustrated fortunes with dynamic particle shockwaves.
- **❄️ Dual-Physics Particle System**: Native HTML5 Canvas rendering crystalline snowfall influenced by gentle wind alongside buoyant golden fireplace embers at a steady 60 FPS.
- **🎵 Procedural Web Audio Engine**: Zero external audio files required! Synthesizes vintage music-box chimes, delicate bell chords, and warm atmospheric drones natively via the Web Audio API.
- **⏳ Clockwork Christmas Countdown**: A dynamic Victorian-inspired countdown tracker to Christmas midnight.
- **🕯️ Spectral Hearth Interactive Chamber**: Stoke the ghost flames between emerald chill and crimson warmth with real-time lighting feedback.

## 🚀 Quick Start / Local Setup

This project is completely self-contained with zero runtime dependencies.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/nocturne-noel.git
   cd nocturne-noel
   ```

2. **Open in any browser:**
   Simply double-click `index.html` or serve it locally:
   ```bash
   # Using Python 3
   python3 -m http.server 8000
   ```
   Visit `http://localhost:8000` in your modern web browser.
